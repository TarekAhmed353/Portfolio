# Tarek Ahmed: Portfolio

My personal portfolio website. It covers who I am, what I work with, my education and my projects, and how to get in touch.

> Work in progress. I'm building it one section at a time.

## Tech stack

- Next.js 16 (App Router) with TypeScript
- Tailwind CSS 4
- Motion for animations
- react-icons and lucide-react for icons
- Web3Forms for the contact form
- Deployed on Vercel

## Theme

The site has a light and a dark theme with a toggle. On the first visit it follows your system setting, and it remembers your choice after that. The colours are indigo as the main accent and sky blue as the secondary one.

## Running it locally

```bash
git clone https://github.com/TarekAhmed353/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Then open http://localhost:3000.
